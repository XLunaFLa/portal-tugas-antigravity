# Portal Tugas Antigravity 🎓

Website asisten tugas kuliah, kuis online, dan forum diskusi berbasis AI generasi terbaru (Google Gemini Engine) dan Supabase, dirancang untuk digunakan lintas perangkat tanpa login.

## 🚀 Fitur Unggulan
- **Zero-Login**: Akses instan dari laptop mana pun tanpa perlu login.
- **Multimodal Quiz Solver**: Cukup tekan `Ctrl + V` di halaman web untuk menempelkan screenshot soal kuis langsung dari clipboard.
- **Jawaban Khas Mahasiswa UT**: Terstruktur rapi, opsi yang tepat di baris teratas, penjelasan singkat padat, dan referensi modul di akhir.
- **1-Click Salin ke WordPad**: Sekali klik langsung siap di-paste (`Ctrl + V`) ke WordPad atau Word.
- **Tersimpan di Cloud**: Seluruh data dan gambar tersimpan di database Supabase kamu.

## 🛠️ Variabel Lingkungan (Environment Variables di Vercel)
- `GEMINI_API_KEY`: Kunci API Google AI Studio
- `NEXT_PUBLIC_SUPABASE_URL`: URL project Supabase kamu
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`: Supabase Anon Public Key
- `SUPABASE_SERVICE_ROLE_KEY`: Supabase Service Role Key
